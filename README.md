# 廖铮潇 · AI 产品经理作品集

线上地址：[www.yexx.store](https://www.yexx.store/)

个人作品集：CiteWise、智能排班助手、FlagForge、EchoWalk、福链智图、AI 工作流与工程实践，以及实习和学科背景。

## 本地查看

直接用浏览器打开 `index.html`。样式、交互脚本和展示图片均内嵌在 HTML 中，无需安装依赖；访问 GitHub 与在线演示链接需要联网。

也可在目录内运行 `python -m http.server 8080` 后打开 `http://localhost:8080`。

## 文件说明

- `index.html`：与 2026-10-14 线上部署一致的完整静态源码。
- `edgeone.json`：静态输出目录为仓库根目录，关闭依赖安装与构建。
- `.gitignore`：排除系统文件和本地缓存。

## 部署

目前线上站点使用腾讯云 EdgeOne Makers 的文件上传部署，本仓库尚未与 EdgeOne 自动构建关联。更新网站时可将 `index.html` 打包为 ZIP 上传到原项目；或在控制台主动关联本仓库，实现后续 Git 部署。

PDF 为独立的 A4 阅读版本，在本地交付，未包含在源码仓库中。
